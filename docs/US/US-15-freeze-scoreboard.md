# US-15: Freeze Scoreboard

**As an** admin,
**I want** membekukan tampilan scoreboard publik beberapa saat sebelum event berakhir,
**So that** posisi akhir tidak ketahuan publik sampai closing ceremony.

## Acceptance Criteria

- [ ] Tombol "Freeze Scoreboard" tersedia di dashboard
- [ ] Saat difreeze: scoreboard publik berhenti update (tampilkan data saat freeze dilakukan)
- [ ] Saat difreeze: admin masih bisa melihat scoreboard terbaru di dashboard
- [ ] Tidak ada indikator "frozen" di tampilan publik
- [ ] Tombol "Unfreeze" tersedia, setelah diklik scoreboard publik menampilkan data terbaru
- [ ] Status freeze terlihat jelas di dashboard admin
