# US-5: Melihat Hint

**As a** peserta,
**I want** melihat hint untuk soal yang sedang saya kerjakan,
**So that** saya mendapat petunjuk tambahan jika stuck, tanpa kehilangan poin.

## Acceptance Criteria

- [ ] Tombol "Lihat Hint" tersedia di halaman detail soal (jika hint tersedia)
- [ ] Hint dapat dilihat kapan saja tanpa pengurangan poin
- [ ] Semua hint langsung ditampilkan (tidak perlu "beli" satu per satu)
- [ ] Hint ditampilkan dalam urutan yang ditentukan admin
- [ ] Hint mendukung format Markdown
- [ ] Hint hanya tampil jika soal `unlocked` atau `solved`
