# US-12: Monitor Submission Real-time

**As an** admin,
**I want** memonitor semua submission peserta secara real-time,
**So that** saya bisa mendeteksi aktivitas mencurigakan dan memantau progres kompetisi.

## Acceptance Criteria

- [ ] Halaman monitor menampilkan feed submission terbaru (benar & salah)
- [ ] Setiap baris menampilkan: timestamp, username, nama soal, flag yang disubmit, status (benar/salah), IP address
- [ ] Feed diperbarui real-time saat ada submission baru
- [ ] Filter tersedia: per peserta, per soal, per status (benar/salah)
- [ ] Baris dengan submit benar ditandai warna berbeda
